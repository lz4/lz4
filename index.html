LZ4

LZ4 is a lossless compression algorithm, providing compression speed > 500 MB/s per core (>0.15 Bytes/cycle). It features an extremely fast decoder, with speed in multiple GB/s per core (~1 Byte/cycle). A high compression derivative, called LZ4_HC, is available, trading customizable CPU time for compression ratio. LZ4 library is provided as open source software using a BSD license.

The reference system uses a Core i7-9700K CPU. <div class="row"> <div class="col-md-4 text-justify"> <h2>Transferring dynamic content</h2> <p> Dynamic content, such as network packets, RPCs or database replication, is compressed, sent over the network, and decompressed, the three at the same time. </p> <p> <strong>Default settings, or a single compression thread.</strong> By default, on this system, <code>lz4</code> compresses with 6 threads, <code>pigz</code> with 8, <code>zstd</code> with 2, <code>gzip</code> and <code>lzop</code> with 1. A single thread : <code>lz4 -T1</code>, <code>zstd -T1</code>, <code>pigz -p 1</code>. </p> <p>Each bar measures, for instance for <code>lz4 -1</code> :</p> <pre>lz4 -1 -c &lt; silesia.tar | LINK | lz4 -d -c &gt; /dev/null</pre> <p> where <code>LINK</code> limits the speed of the network (see <a href="https://github.com/lz4/lz4/blob/gh-pages/bench/bench-pipeline.sh">bench-pipeline.sh</a>). </p> <p class="benchmark-versions" data-scenario="transfer"></p> </div> <div class="col-md-8"> <div class="benchmark-links" data-scenario="transfer"></div> <div class="benchmark-chart" data-scenario="transfer" style="height:26em;"></div> </div> </div> </div> </div> </div> ## Documentation The LZ4 block compression format is detailed within [lz4_Block_format](https://github.com/lz4/lz4/blob/release/doc/lz4_Block_format.md).
